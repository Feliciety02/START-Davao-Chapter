# START portal phone captures

These six unedited PNGs were captured from the installed START web app on a USB-connected realme RMX2151 on November 16, 2026 (Asia/Singapore). Each image is 1080 × 2400 pixels. The Regional Representative account's practice view was used for the Lead and Member screens. Captures with visible personal names or email addresses were kept outside this repository.

Capture command: `adb shell screencap -p /sdcard/Download/start-device-current.png`, followed by `adb pull` to the computer. The selected files were copied here without changing their pixels.
